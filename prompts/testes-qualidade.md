Atue como Líder de Qualidade e Engenharia de Testes.

Analise o projeto e construa uma estratégia completa de validação dividida em:

1. Testes unitários
2. Testes de contrato
3. Testes de integração
4. Testes E2E
5. Testes de segurança
6. Testes de performance
7. Testes de acessibilidade
8. Testes de recuperação de falhas

Primeiro execute ou registre o baseline atual.

Depois identifique:

- funcionalidades sem teste;
- testes frágeis;
- testes que não detectam bugs reais;
- falsos positivos;
- cobertura enganosa;
- ausência de casos de erro;
- ausência de testes de concorrência;
- ausência de testes de autorização;
- regressões prováveis.

Para cada teste, informe:

- objetivo;
- entrada;
- comportamento esperado;
- ferramenta;
- ambiente;
- evidência;
- critério PASS/FAIL.

Nunca remova um teste apenas porque ele falhou. Determine primeiro se o
problema está no produto, no teste ou no ambiente.
