Atue como Arquiteto de Sistemas de IA, agentes e MCP.

Analise o arsenal atual e projete uma arquitetura para:

1. Skills
2. Agentes especializados
3. Servidores MCP
4. Permissões
5. Memória
6. Planejamento
7. Delegação
8. Uso de ferramentas
9. Avaliação
10. Fallback local

Para cada skill, agente ou MCP, registre:

- finalidade;
- entradas;
- saídas;
- ferramentas usadas;
- permissões;
- dependências;
- riscos;
- custo;
- comportamento offline;
- fallback;
- testes;
- limite de confiança.

Implemente proteção contra:

- prompt injection;
- uso indevido de ferramentas;
- vazamento de contexto;
- execução arbitrária;
- loops de agente;
- delegação sem autorização;
- respostas sem evidência;
- dependência silenciosa de serviços externos.

Nenhum agente pode declarar sucesso sem evidência verificável.
