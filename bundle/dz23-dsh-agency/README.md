# Agência de especialistas DSH

Biblioteca de **87 papéis de agente** (prompts para o campo `agent-instructions`), um Diretor que orquestra os pods, e scripts que auditam o conjunto.

- **Versão:** 1.0.0 — ver [CHANGELOG](CHANGELOG.md)
- **Instalação:** [quickstart](DSH_QUICKSTART.md) — 5 passos
- **Referência canônica:** [documento canônico](DSH_COMPLETE_SPECIALIST_AGENCY.md)
- **Perfis:** [01–24](DSH_SPECIALIST_AGENT_CATALOG.md), [25–64](DSH_SPECIALIST_AGENT_CATALOG_EXPANDED.md), [65–87](DSH_SPECIALIST_AGENT_CATALOG_VERTICALS.md)
- **Gerar agentes prontos:** `python build.py` (cria `agents/` com 88 arquivos)
- **Antes de commitar:** `python check_sizes.py` + `python check_consistency.py`
- **Integração opcional:** [integrações](DSH_INTEGRATIONS.md)
- **Histórico:** [CHANGELOG](CHANGELOG.md)
