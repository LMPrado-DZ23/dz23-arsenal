# Checagens de nome (triagem, não liberação jurídica)

**Aviso:** o que está aqui é triagem para não escolher um nome obviamente ruim. **Não é liberação
jurídica.** Antes de gastar dinheiro no nome, um advogado de marcas do seu país faz a busca de verdade.

## O teste central: não confusamente similar

O escritório de marcas recusa um nome que seja **confusamente similar** a outro, da mesma categoria, em
**som, aparência ou sentido**. Use o mesmo teste ao cortar os candidatos:

- Sem trocadilho com o nome do original; sem o gêmeo "-ly" do nome deles.
- Não parecer, soar ou significar o mesmo que o original **nem** que outro app da mesma categoria.
- Curto, soletrável depois de ouvir uma vez, sem sentido estranho em idiomas grandes.

## As checagens, uma linha cada, rodadas

Para cada candidato finalista, uma linha por checagem. **Marque "a rodar", ou o resultado com a data.**
Nunca escreva "disponível" para uma checagem que ninguém rodou.

| checagem | onde |
|---|---|
| Marca US | tmsearch.uspto.gov, a classe do app (normalmente 9 e 42) |
| Marca EU | euipo.europa.eu eSearch, ou TMview para vários escritórios |
| Canadá | base de marcas ised-isde.canada.ca |
| Global | WIPO Global Brand Database |
| Domínio | `whois nome.com`, ou a busca do registrador |
| App Store e Play | buscar o nome exato |
| Handles | X, Instagram, TikTok, GitHub |
| Web | buscar "nome + categoria" |

## O que nunca fazer

- Usar o nome do original no seu nome, anúncio ou listagem de loja.
- Escrever "disponível" sem ter rodado a checagem.
- Tratar a triagem como liberação jurídica. Um nome que passa aqui ainda pode colidir — o advogado
  decide, não este checklist.
