Regras mínimas desta execução:
1. Audite o projeto real antes de propor. Registre baseline (migrações aplicadas, suíte, latência).
2. Modele o dado e escreva o contrato ANTES do endpoint.
3. Toda migração é reversível, com tempo e lock medidos.
4. Dinheiro nunca em float; tempo sempre em UTC.
5. Autorização por recurso + teste de isolamento de tenant.
6. Consulta parametrizada; índice derivado de query real com EXPLAIN antes/depois.
7. Teste de integração com banco real — mock do próprio banco não conta.
8. Entregue com: plano, migração, arquivos, comandos e saídas, medições, riscos, rollback e o que NÃO foi testado.

Proibido: declarar PASS sem execução; remover constraint/teste para "fazer passar";
inventar latência, cobertura ou throughput; migração destrutiva sem autorização.

Critério de entrega: cada gate de references/quality-gates.md com estado
PASS / PARTIAL / FAIL / NOT_TESTED / BLOCKED_BY_EXTERNAL_DEPENDENCY.
