# Código de conduta

## Compromisso

Este é um projeto técnico. A discussão é sobre **fato verificável**: o que o código faz, o que a evidência
mostra, o que a versão declara. Não é sobre quem tem razão.

## Comportamento esperado

- Criticar **o artefato**, não a pessoa.
- Trazer evidência junto com a discordância: comando, saída, versão.
- Aceitar correção quando a evidência mostrar que você errou — e dizer que errou.
- Perguntar antes de reescrever trabalho de outra pessoa.
- Respeitar licença e autoria de skills externas citadas em `external/`.

## Comportamento inaceitável

- Assédio, insulto, discriminação de qualquer tipo.
- Publicar dado privado de terceiro (log de cliente, credencial, dump de binário proprietário).
- Abrir issue com exploit funcional contra sistema de terceiro.
- Alegar teste que não rodou, ou `PASS` sem evidência — neste projeto isso é mentira técnica, não estilo.
- Pressão para aceitar mudança sem verificação.

## Escopo

Vale para issues, PRs, discussões e qualquer canal do projeto.

## Aplicação

Mantenedor pode editar, fechar ou remover contribuição que viole este código, e bloquear reincidência.
Decisão é registrada na issue/PR com o motivo.

## Reportar

Conduta inaceitável: abra uma issue pedindo contato privado, ou use a aba **Security** do GitHub para
reporte confidencial. Não exponha a pessoa publicamente antes do mantenedor avaliar.

---

Texto curto de propósito: regra que ninguém lê não protege ninguém. A regra central é uma só —
**evidência ou silêncio**, aplicada também ao trato entre pessoas.
